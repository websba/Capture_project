  CaptureMore（螢幕連續擷取與拼圖工具）
  readme.txt

【專案簡介】
  這是一個 Windows 桌面小工具，用來連續框選截圖、依欄數排列預覽，
  再一鍵將多張截圖拼成一張圖並複製到剪貼簿。
  目標是解決傳統 Snipping Tool「一次只能截一張、要手動拼圖」的痛點。


--------------------------------------------------------------------------------
一、使用說明
--------------------------------------------------------------------------------

1. 啟動方式（擇一）

  A. 開發／本機（最快）
     - 雙擊專案根目錄的 start.bat
     - 或執行：
       env\.venv\Scripts\python.exe main.py

  B. 發行版 onedir（啟動較快，建議日常使用）
     - 開啟資料夾：build\CaptureMore_onedir\
     - 雙擊 CaptureMore.exe
     - 注意：必須與同目錄的 _internal 資料夾一起保留／一起複製

  C. 發行版 onefile（單檔方便攜帶，啟動較慢）
     - 雙擊：build\CaptureMore_onefile\CaptureMore.exe
     - 第一次／每次啟動都會先解壓暫存檔，因此視窗出現會慢一點

2. 基本操作

  [+]      進入全螢幕框選模式（類似 Windows 剪取工具）
           - 左鍵拖曳：框選要截的範圍
           - Esc 或 右鍵：取消本次框選
           - 截圖後，縮圖會出現在視窗下方

  [~]      長截圖（捲動拼接），適合截超過一個畫面高度的網頁或文件
           - 先和 + 一樣左鍵拖曳，框出要重複擷取的範圍
           - 放開後框線變成青色外框，下方（空間不足時改上方）出現 OK 列
           - 框內是「鏡頭」，不屬於本程式視窗。滑鼠滾輪與點擊會直接作用
             在下面那個視窗，照平常方式往下（或往上）捲動即可
           - 每次捲動停下來，程式會自動把新出現的內容接到同一張長圖，
             OK 列會顯示「已接 N 列」
           - 捲太快、跳過中間內容時會顯示「請往回捲一點再試」，
             往回捲一些讓畫面重疊即可繼續
           - 按 OK 完成，長圖會當成一張截圖加進下方縮圖
           - Esc 或 在青色外框上按右鍵：取消本次長截圖

  [每列 n] 數字選擇框，範圍 1～6，預設 2
           - 控制下方縮圖與最終拼圖的「每列張數」
           - 例如選 2：兩張一排；選 3：三張一排

  [COPY]   將目前所有截圖依「每列」設定拼成一張圖，並寫入剪貼簿
           - 之後可到 Word、PowerPoint、聊天軟體、繪圖程式等直接貼上

  [×]      每張縮圖右上角可刪除該張（截錯時方便修正）

3. 建議工作流程

  按 + 截第一張，或按 ~ 捲出一張長圖 → 需要多張時再按 +
  → 調「每列」看排版 → 按 COPY → 到目標軟體 Ctrl+V 貼上


--------------------------------------------------------------------------------
二、開發歷程
--------------------------------------------------------------------------------

日期：2026-07-31

1. 環境建置
   - 新增 env 資料夾，建立 Python 3.11 虛擬環境（env\.venv）
   - 後續依賴安裝與執行皆在虛擬環境中進行

2. 功能實作（初版）
   - UI：tkinter（+、每列 Spinbox、COPY、縮圖區）
   - 框選：全螢幕遮罩，支援多螢幕虛擬桌面
   - 截圖：mss（隱藏主視窗後擷取，避免把自己截進去）
   - 拼圖：Pillow（依欄數網格拼接，保留原圖像素）
   - 剪貼簿：pywin32 / win32clipboard（CF_DIB 影像格式）
   - 程式結構：
       main.py
       app\main_window.py      主視窗
       app\snip_overlay.py     框選遮罩
       app\collage.py          拼圖
       app\clipboard_win.py    寫入剪貼簿
       requirements.txt

3. 備份
   - 初版程式碼備份於：
     backup\Capture_project_202607311701_初版\

4. 便利啟動
   - 新增 start.bat，雙擊即可用虛擬環境啟動 main.py

5. 打包發行
   - 使用 PyInstaller
   - 單檔版：build\CaptureMore_onefile\CaptureMore.exe
     （約 16～17 MB，方便單檔分發，啟動需解壓故較慢）
   - 資料夾版：build\CaptureMore_onedir\
     （CaptureMore.exe + _internal，啟動較快）


--------------------------------------------------------------------------------
三、注意事項
--------------------------------------------------------------------------------

1. 平台
   - 目前以 Windows 為目標（剪貼簿使用 win32clipboard）
   - 未在 macOS / Linux 驗證

2. 解析度
   - 截圖為螢幕實際像素（1:1），無法超過螢幕本身解析度
   - 視窗下方縮圖較小僅供預覽（預覽上限約 180px），不影響 COPY 出去的圖

3. 多螢幕
   - 框選遮罩會覆蓋整個虛擬桌面，可跨螢幕框選

4. onedir 發行
   - 不可只複製 CaptureMore.exe，必須連同 _internal 一起帶走
   - 否則程式無法啟動

5. onefile 發行
   - 啟動較慢屬正常現象（需先解壓到暫存目錄）
   - 部分防毒軟體可能對「單檔解壓執行」較敏感

6. 開發環境
   - 請使用專案內虛擬環境，避免污染系統 Python
   - 依賴見 requirements.txt：mss、Pillow、pywin32
   - 重新安裝：
       env\.venv\Scripts\pip.exe install -r requirements.txt

7. 重新打包（需已安裝 PyInstaller）
   - onefile：
       env\.venv\Scripts\pyinstaller.exe --noconfirm --clean
         --distpath build\CaptureMore_onefile
         --workpath build\CaptureMore_onefile\work
         build\CaptureMore_onefile\CaptureMore.spec
   - onedir：
       env\.venv\Scripts\pyinstaller.exe --noconfirm --clean
         --distpath build
         --workpath build\CaptureMore_onedir\work
         build\CaptureMore_onedir\CaptureMore_onedir.spec
